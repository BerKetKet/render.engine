# Spacing Settings Device Fit v4 — Experiments & Results (`v1.11.18`)

All runs evaluated under `KINDLE_RENDER_STRICT_HARFBUZZ=1` (HarfBuzz `6.0.0`) via `tools/lab_spacing/score_spacing.py` against `data/spacing_caps` (pages 2–5 summed; page 1 ignored).

- **v1.11.17 Baseline**: Standard `4,578,050`, Compact `5,831,191`, Large `5,507,764`, **GRAND TOTAL `15,917,005`** (vs `v1.11.14` `26,307,438`).
- **v1.11.18 Final**: Standard `4,290,767` (`-287,283`), Compact `4,591,765` (`-1,239,426`), Large `5,211,916` (`-295,848`), **GRAND TOTAL `14,094,448` (`-1,822,557` px vs `v1.11.17`, `-12,212,990` px / `-46.4%` vs `v1.11.14`)**. Zero cells worsened `> 0.6%`.
