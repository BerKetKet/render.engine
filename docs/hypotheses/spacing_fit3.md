# Spacing Settings Device Fit v3 — Experiments & Results (`v1.11.17`)

All runs evaluated under `KINDLE_RENDER_STRICT_HARFBUZZ=1` (HarfBuzz `6.0.0`) via `tools/lab_spacing/score_spacing.py` against `data/spacing_caps` (pages 2–5 summed; page 1 ignored).

- **v1.11.16 Baseline**: Standard `4,871,548`, Compact `5,903,914`, Large `6,909,148`, **GRAND TOTAL `17,684,610`** (vs `v1.11.14` `26,307,438`).
- **v1.11.17 Final**: Standard `4,578,050` (`-293,498`), Compact `5,831,191` (`-72,723`), Large `5,507,764` (`-1,401,384`), **GRAND TOTAL `15,917,005` (`-1,767,605` px vs `v1.11.16`, `-10,390,433` px / `-39.5%` vs `v1.11.14`)**. Zero cells worsened anywhere across all 60 runs!
